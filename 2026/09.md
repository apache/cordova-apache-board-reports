## Status report for the Apache Cordova project - Sept 2026

## Description

A platform for building native mobile applications using HTML, CSS and
JavaScript.

## Project Status

**Current project status:**

Our current work focuses on staying up to date by making fixes and
improvements to our core platforms and plugins.

Our status dashboard at https://apache.github.io/cordova-status/ remains
mostly all green.

There are no issues requiring board attention at this time.

## Community Health

Overall, the community health is strong. The ASF Project Statistics
gives the project a Community Health Score (Chi): 4.70 (Healthy)

We continue to see valuable contributions from a dedicated group of
individuals who actively test, report issues, and submit PRs to address
their findings in future releases.

This quarter, we primarily focused on improving some plugins and
platforms.

A large portion of this quarter's activity was focused on improving the
In-App Browser plugin, as well as fixing the status bar and edge-to-edge
functionality of the Android core platform. There is still on going
improvements toward the status bar functionality to be more inlined with
the behavior of the iOS core platform. There were contributions that
landed in a patch release for the iOS core platform and file transfer
plugin.

We are also updating the repository's Dependabot configuration to
include GitHub Actions dependencies, so that our workflows remain
up-to-date.

Overall, the project remains stable and continues to see strong
activity.

Github discussions is how our community supports each other and is live
at https://github.com/apache/cordova/discussions. All discussions are
forwarded to the 'issues' list.
